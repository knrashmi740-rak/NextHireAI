Python Basics

Learn the fundamentals of Python programming, syntax, variables, indentation and basic statements.

📘 Concept Summary

Python is a high-level, interpreted and general-purpose programming language. It is easy to learn because its syntax is simple and readable.

Python is widely used in web development, automation, data science, artificial intelligence and machine learning.

⭐ Important Concepts

  • Python is an interpreted language.
  • Python uses indentation to define code blocks.
  • Python is dynamically typed.
  • Python supports object-oriented programming.
  • Python is case-sensitive.

📝 First Python Program

print("Hello World")

⭐ Comments

Comments are used to explain code and are ignored by the Python interpreter. 

# This is a comment

print("Hello Python")

💡 Indentation

Python uses spaces or indentation instead of curly brackets to define blocks of code. 

if 10 > 5:
    print("10 is greater")

Conditional Statements

Conditional statements are used to make decisions in Python programs.

📘 Concept Summary

Python provides if, elif and else statements for decision making.

⭐ if Statement

age = 20

if age >= 18:
    print("Eligible")

⭐ if-else Statement

age = 16

if age >= 18:

else:
    print("Minor")

⭐ if-elif-else

else:
    print("C Grade")

{% elif topic == "loops" %}

Loops

Loops are used to execute a block of code repeatedly.

📘 Concept Summary

Python mainly provides for loops and while loops. The break and continue statements control loop execution.

⭐ for Loop

for i in range(1, 6):
    print(i)

⭐ while Loop

i = 1

while i <= 5:
    print(i)
    i += 1

⭐ break

The break statement immediately terminates a loop. 

for i in range(10):

    if i == 5:
        break

    print(i)

⭐ continue

The continue statement skips the current iteration. 

for i in range(5):

    if i == 2:
        continue

    print(i)

{% elif topic == "exceptions" %}

Exception Handling

Exception handling is used to handle runtime errors without stopping the complete program.

📘 Concept Summary

Python uses try, except, else and finally blocks to handle exceptions.

⭐ try-except

try:

    number = int(input("Enter number: "))

    print(10 / number)

except ZeroDivisionError:

    print("Cannot divide by zero")

except ValueError:

    print("Invalid input")

⭐ finally

The finally block executes whether an exception occurs or not. 

try:

    print("Hello")

except:

    print("Error")

finally:

    print("Completed")

💡 Important Tip

Use specific exception types whenever possible instead of using a general except block.

Object-Oriented Programming

Object-Oriented Programming, or OOP, is a programming approach based on classes and objects.

📘 Concept Summary

OOP helps organize large programs by combining data and functions inside classes.

⭐ Important OOP Concepts

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

⭐ Class and Object

class Student:

    def __init__(self, name):

        self.name = name


    def display(self):

        print(self.name)


student = Student("Rashmitha")

student.display()

⭐ Inheritance

Inheritance allows one class to acquire properties and methods from another class. 

class Animal:

    def speak(self):

        print("Animal sound")


class Dog(Animal):

    def bark(self):

        print("Dog barking")


dog = Dog()

dog.speak()

dog.bark()

Problem Solving

Problem solving is one of the most important skills for coding interviews and placement preparation.

📘 Concept Summary

Good problem solving involves understanding the problem, planning the solution, writing code and testing the result.

⭐ Problem Solving Steps

  • Understand the problem.
  • Identify inputs and outputs.
  • Break the problem into smaller steps.
  • Create an algorithm.
  • Write the code.
  • Test different cases.
  • Optimize the solution if necessary.

📝 Example Problem

Find the largest of two numbers. 

a = 10
b = 20

if a > b:

    print(a)

else:

    print(b)

⭐ Important Practice Areas

  • Number problems
  • String problems
  • List problems
  • Searching
  • Sorting
  • Pattern programs
  • Recursion
  • Basic algorithms

💡 Important Tip

First understand the logic of the problem. Then write the code.
