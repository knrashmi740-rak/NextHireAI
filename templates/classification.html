Classification

Learn how to identify the odd item and group similar items together.

📘 Concept Summary

Classification questions are based on finding similarities and differences between words, numbers, letters, or objects. The task is to identify the item that does not belong to the group.

⭐ Important Concepts

  • Find the common relationship between items.
  • Identify the odd one out.
  • Classification can be based on words, numbers, letters, or objects.
  • Check category, function, shape, or properties.

⭐ Important Methods

Word Classification:

Apple, Mango, Banana, Car
(Car is different because others are fruits)
Number Classification:

2, 4, 6, 9
(9 is different because others are even numbers)
Letter Classification:

A, E, I, O, B
(B is different because others are vowels)

💡 Tricks

  • Find the group formed by maximum items.
  • Look for common properties.
  • Check numbers for odd/even, prime, or square patterns.
  • Do not select an item only based on appearance.

📝 Example

Find the odd one out:

Rose, Lotus, Lily, Carrot

Rose → Flower
Lotus → Flower
Lily → Flower

Carrot → Vegetable

Answer = Carrot
