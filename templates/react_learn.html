React Basics

React is a JavaScript library used to build interactive and reusable user interfaces, especially for web applications.

📘 Concept Summary

React was created by Facebook and is now maintained by Meta and the open-source community.

React applications are built using reusable components. Instead of creating one large HTML page, we divide the interface into smaller independent pieces.

React uses JavaScript to control what appears on the screen and automatically updates the user interface when application data changes.

⭐ Why React?

  • Reusable components
  • Fast and interactive user interfaces
  • Component-based architecture
  • Large developer community
  • Useful for single-page applications
  • Works with many JavaScript libraries and tools

⭐ React Component

A component is a reusable part of a user interface. For example, a navigation bar, button, profile card or login form can be created as a component.

function Welcome() {

    return <h1>Welcome to React</h1>;
}

📝 Rendering a Component

function App() {

    return (
        <div>
            <h1>My Application</h1>
        </div>
    );
}

💡 Important Tip

React is based on components. Learn components well before moving to advanced concepts such as hooks and routing.

{% elif topic == "jsx" %}

JSX

JSX is a syntax extension for JavaScript that allows developers to write HTML-like code inside JavaScript.

📘 Concept Summary

JSX makes React code easier to read and write. Although JSX looks like HTML, it is transformed into JavaScript before the browser executes it.

⭐ Basic JSX Example

const element = <h1>Hello React</h1>;

Here the HTML-like h1 element is written directly inside JavaScript.

⭐ JSX Expressions

JavaScript expressions can be placed inside JSX using curly braces.

const name = "Rashmitha";

const element = <h1>Hello {name}</h1>;

⭐ JSX Rules

  • Return a single parent element.
  • Close all HTML elements properly.
  • Use className instead of class.
  • Use curly braces for JavaScript expressions.
  • JavaScript expressions should be valid inside JSX.

💡 Important Tip

JSX is not exactly HTML. It looks similar to HTML, but it follows JavaScript and React rules.

{% elif topic == "components" %}

Components

Components are the building blocks of React applications.

📘 Concept Summary

A component is a reusable piece of user interface. Large applications are divided into multiple components so that each part can be developed and maintained separately.

⭐ Functional Component

function Greeting() {

    return <h1>Hello!</h1>;
}

⭐ Using a Component

function App() {

    return (
        <div>
            <Greeting />
        </div>
    );
}

⭐ Advantages

  • Code reusability
  • Easy maintenance
  • Better organization
  • Independent development
  • Reusable user-interface elements
{% elif topic == "props" %}

Props

Props are used to pass data from one component to another component.

📘 Concept Summary

Props, short for properties, allow a parent component to send information to a child component.

Props are read-only. A child component should not directly modify the props received from its parent.

📝 Example

function Student(props) {

    return <h2>Name: {props.name}</h2>;
}

function App() {

    return <Student name="Rashmitha" />;
}

⭐ Destructuring Props

function Student({ name, age }) {

    return <p>{name} - {age}</p>;
}

💡 Important Tip

Props are mainly used when data needs to flow from a parent component to a child component.

{% elif topic == "state" %}

State

State stores data that can change during the lifetime of a React component.

📘 Concept Summary

When state changes, React can re-render the component so that the user interface displays the updated data.

⭐ State Example

import { useState } from "react";

function Counter() {

    const [count, setCount] = useState(0);

    return (
        <button onClick={() => setCount(count + 1)}>
            {count}
        </button>
    );
}

⭐ Important Points

  • State belongs to a component.
  • State can change during execution.
  • Updating state causes a re-render.
  • useState is commonly used to manage state.
{% elif topic == "events" %}

Events

React events allow an application to respond to user actions such as clicks, typing and form submission.

⭐ Click Event

function App() {

    function handleClick() {
        alert("Button clicked");
    }

    return (
        <button onClick={handleClick}>
            Click Me
        </button>
    );
}

⭐ Common Events

  • onClick
  • onChange
  • onSubmit
  • onMouseEnter
  • onKeyDown
  • onFocus
{% elif topic == "conditional-rendering" %}

Conditional Rendering

Conditional rendering means displaying different content depending on a condition.

⭐ Using if

function Welcome({ loggedIn }) {

    if(loggedIn) {
        return <h1>Welcome Back</h1>;
    }

    return <h1>Please Login</h1>;
}

⭐ Ternary Operator

{isLoggedIn ? <p>Dashboard</p> : <p>Login</p>}

⭐ Logical AND

{isAdmin && <button>Delete</button>}
{% elif topic == "lists" %}

Lists & Keys

React commonly uses JavaScript arrays to display multiple elements.

📘 Concept Summary

The map() method is frequently used to transform an array into a list of React elements.

📝 Example

const students = ["Ravi", "Anu", "Meena"];

function App() {

    return (
        <ul>
            {students.map(student => (
                <li>{student}</li>
            ))}
        </ul>
    );
}

⭐ Keys

Keys help React identify which list elements have changed, been added or removed.

{students.map(student => (
    <li key={student}>{student}</li>
))}
{% elif topic == "forms" %}

Forms

Forms allow users to enter information such as names, emails, passwords and search values.

📘 Concept Summary

React commonly uses state to control form values. Such forms are called controlled components.

📝 Example

function Form() {

    const [name, setName] = useState("");

    return (
        <input
            value={name}
            onChange={e => setName(e.target.value)}
        />
    );
}

⭐ Common Form Elements

  • input
  • textarea
  • select
  • button
  • checkbox
  • radio button
{% elif topic == "hooks" %}

React Hooks

Hooks allow functional components to use features such as state and side effects.

📘 Concept Summary

Hooks are JavaScript functions provided by React. They must normally be called at the top level of a React function component or another custom hook.

⭐ Common Hooks

  • useState
  • useEffect
  • useContext
  • useRef
  • useMemo
  • useCallback

💡 Important Tip

Start by understanding useState and useEffect clearly. They are among the most frequently used React hooks.

{% elif topic == "usestate" %}

useState

useState is a React Hook used to create and update state inside a functional component.

⭐ Syntax

const [state, setState] = useState(initialValue);

📝 Example

import { useState } from "react";

function Counter() {

    const [count, setCount] = useState(0);

    return (
        <button onClick={() => setCount(count + 1)}>
            Count: {count}
        </button>
    );
}

⭐ Important Points

  • Initial state is provided to useState.
  • The setter function updates the state.
  • State updates can cause the component to re-render.
{% elif topic == "useeffect" %}

useEffect

useEffect is used to perform side effects in React components.

📘 What is a Side Effect?

A side effect is an operation that happens outside the normal calculation of the component UI.

  • Fetching data
  • Updating the document title
  • Subscribing to an event
  • Starting a timer

📝 Example

import { useEffect } from "react";

useEffect(() => {
    console.log("Component rendered");
}, []);

⭐ Dependency Array

The dependency array tells React when the effect should run again.

{% elif topic == "routing" %}

React Router

React Router allows a React application to display different components for different URLs.

📘 Concept Summary

Routing is useful for applications that contain multiple pages or views such as Home, About, Profile and Dashboard.

⭐ Example

import { BrowserRouter, Routes, Route } from "react-router-dom";

function App() {

    return (
        <BrowserRouter>
            <Routes>
                <Route path="/" element={<Home />} />
                <Route path="/about" element={<About />} />
            </Routes>
        </BrowserRouter>
    );
}

⭐ Benefits

  • Multiple application views
  • Navigation without full page reloads
  • Organized application structure
{% elif topic == "api" %}

API Integration

React applications often communicate with backend services through APIs.

📘 Concept Summary

An API allows the frontend application to request or send data to a backend server.

A common way to make HTTP requests in JavaScript is using fetch().

📝 Example

fetch("https://example.com/api/users")
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.log(error));

⭐ Common HTTP Methods

  • GET → Retrieve data
  • POST → Create data
  • PUT → Update data
  • DELETE → Delete data
{% elif topic == "project-structure" %}

React Project Structure

A good project structure makes a React application easier to understand and maintain.

⭐ Common Structure

src/
  components/
  pages/
  assets/
  App.jsx
  main.jsx

⭐ Components Folder

Reusable UI components such as buttons, navigation bars, cards and forms can be placed inside the components folder.

⭐ Pages Folder

Pages usually represent larger views such as Home, Login, Dashboard and Profile.

💡 Important Tip

Keep reusable components separate from page-level components to make the project easier to maintain.

React Problem Solving

React problem solving requires understanding both JavaScript logic and React's component-based approach.

📘 Problem Solving Steps

  • Understand the requirement.
  • Break the interface into components.
  • Identify the data required.
  • Decide which data should be state.
  • Pass data using props when required.
  • Handle user events.
  • Connect APIs when necessary.
  • Test different user interactions.
  • Improve the component structure.

📝 Example Problem

Create a counter that increases whenever the user clicks a button.

const [count, setCount] = useState(0);

<button onClick={() => setCount(count + 1)}>
    Count: {count}
</button>

⭐ Important Practice Areas

  • Components
  • Props
  • State
  • Forms
  • Events
  • API calls
  • Routing
  • Hooks
  • Reusable UI design

💡 Important Tip

First understand the UI and data flow. Then decide which components, props and state are required to solve the problem.
