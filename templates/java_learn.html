Java Basics

Learn the fundamental concepts of Java programming, program structure, syntax, compilation and execution.

📘 Concept Summary

Java is a high-level, object-oriented and general-purpose programming language. It was designed with the goal of allowing Java programs to run on different platforms.

Java programs are first converted into bytecode by the Java compiler. This bytecode is then executed by the Java Virtual Machine (JVM).

⭐ Important Features of Java

  • Java is object-oriented.
  • Java is platform independent through the JVM.
  • Java is strongly typed.
  • Java supports exception handling.
  • Java provides automatic memory management.
  • Java is widely used in enterprise and application development.

⭐ JDK, JRE and JVM

  • JDK: Java Development Kit used to develop Java programs.
  • JRE: Java Runtime Environment used to run Java programs.
  • JVM: Java Virtual Machine executes Java bytecode.

📝 First Java Program

public class Main {

    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

⭐ Understanding main()

The main() method is the starting point of a Java application. The JVM begins execution from this method.

public static void main(String[] args)

💡 Important Tip

Java is case-sensitive. For example, System and system are different names.

{% elif topic == "variables" %}

Variables & Data Types

Variables are used to store information that a program needs to process.

📘 Concept Summary

A variable is a named memory location that stores a value. Every variable in Java has a specific data type.

Java is strongly typed, so the type of a variable must be known when it is declared.

⭐ Variable Syntax

dataType variableName = value;

📝 Example

int age = 20;
double percentage = 85.5;
char grade = 'A';
boolean passed = true;
String name = "Rashmitha";

⭐ Primitive Data Types

  • byte: Small integer values.
  • short: Small integer values larger than byte.
  • int: Commonly used integer type.
  • long: Used for large integer values.
  • float: Decimal values.
  • double: More precise decimal values.
  • char: Stores a single character.
  • boolean: Stores true or false.

⭐ Non-Primitive Data Types

Examples include String, arrays, classes and objects. These types can represent more complex data.

💡 Important Tip

Choose the appropriate data type based on the value that needs to be stored.

Operators

Operators are symbols used to perform operations on values and variables.

📘 Concept Summary

Java provides several types of operators including arithmetic, relational, logical, assignment and increment/decrement operators.

⭐ Arithmetic Operators

+   Addition

-   Subtraction

*   Multiplication

/   Division

%   Modulus

📝 Arithmetic Example

int a = 10;
int b = 3;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);
System.out.println(a % b);

⭐ Relational Operators

==   Equal to

!=   Not equal to

>   Greater than

<   Less than

>=   Greater than or equal to

<=   Less than or equal to

⭐ Logical Operators

&&   Logical AND

||   Logical OR

!   Logical NOT

📝 Logical Example

int age = 20;

if(age >= 18 && age <= 60) {
    System.out.println("Valid age");
}
{% elif topic == "conditions" %}

Conditional Statements

Conditional statements allow a program to make decisions based on conditions.

📘 Concept Summary

Java provides if, if-else, else-if and switch statements for decision making.

⭐ if Statement

The if statement executes a block only when its condition evaluates to true.

int age = 20;

if(age >= 18) {
    System.out.println("Eligible");
}

⭐ if-else Statement

The else block executes when the if condition is false.

int marks = 35;

if(marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

⭐ else-if Ladder

if(marks >= 90) {
    System.out.println("A");
} else if(marks >= 75) {
    System.out.println("B");
} else {
    System.out.println("C");
}

⭐ switch Statement

switch is useful when one expression needs to be compared with multiple possible values.

int day = 1;

switch(day) {
    case 1:
        System.out.println("Monday");
        break;

    default:
        System.out.println("Invalid");
}
{% elif topic == "loops" %}

Loops

Loops are used when the same block of code needs to execute repeatedly.

📘 Concept Summary

Java provides for, while and do-while loops. The choice depends on how the repetition should occur.

⭐ for Loop

A for loop is commonly used when the number of iterations is known.

for(int i = 1; i <= 5; i++) {
    System.out.println(i);
}

⭐ while Loop

A while loop checks its condition before executing the loop body.

int i = 1;

while(i <= 5) {
    System.out.println(i);
    i++;
}

⭐ do-while Loop

A do-while loop executes its body at least once before checking the condition.

int i = 1;

do {
    System.out.println(i);
    i++;
} while(i <= 5);

⭐ break and continue

  • break: Immediately terminates the loop.
  • continue: Skips the current iteration.
{% elif topic == "methods" %}

Methods

Methods are reusable blocks of code that perform a particular task.

📘 Concept Summary

Methods help divide a large program into smaller, manageable pieces. They improve code reuse and readability.

⭐ Method Syntax

returnType methodName(parameters) {
    // statements
}

📝 Example

static int add(int a, int b) {
    return a + b;
}

int result = add(10, 20);

⭐ Parameters and Return Value

Parameters allow data to be passed into a method. A return statement sends a result back to the caller.

💡 Advantages of Methods

  • Code reusability
  • Better organization
  • Easy testing
  • Less code repetition
  • Improved readability
{% elif topic == "arrays" %}

Arrays

Arrays are used to store multiple values of the same data type in a single variable.

📘 Concept Summary

An array has a fixed size. Each element is accessed using an index, and Java array indexing starts from 0.

⭐ Creating an Array

dataType[] arrayName = new dataType[size];

📝 Example

int[] numbers = {10, 20, 30, 40, 50};

⭐ Accessing Elements

System.out.println(numbers[0]);
System.out.println(numbers[2]);

The first statement prints 10 and the second prints 30.

⭐ Traversing an Array

for(int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

💡 Important Tip

Array indexes start from 0 and end at length - 1. Accessing an invalid index causes an exception.

Strings

Strings are used to represent sequences of characters and are one of the most commonly used types in Java.

📘 Concept Summary

In Java, String is a class. String objects are immutable, meaning their contents cannot be changed after creation.

⭐ Creating a String

String name = "Java";

System.out.println(name);

  • length()
  • toUpperCase()
  • toLowerCase()
  • charAt()
  • substring()
  • equals()
  • contains()

String text = "Hello Java";

Use equals() when you want to compare the contents of two String objects.

String a = "Java";

System.out.println(a.equals(b));
{% elif topic == "classes" %}

Classes & Objects

Classes and objects are the foundation of object-oriented programming in Java.

📘 What is a Class?

A class is a blueprint that defines the properties and behaviors of objects.

⭐ What is an Object?

An object is an instance of a class. It represents a real entity and can contain data and behavior.

📝 Example

class Student {

    String name;
    int age;
}

Student s1 = new Student();
s1.name = "Rashmitha";
s1.age = 20;

⭐ Constructor

A constructor is a special method used to initialize objects. It has the same name as the class.

Student(String name) {
    this.name = name;
}

💡 Important OOP Concepts

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction
{% elif topic == "inheritance" %}

Inheritance

Inheritance allows one class to acquire properties and methods from another class.

📘 Concept Summary

Inheritance promotes code reuse. The class that provides the features is called the parent or superclass, while the class that inherits them is called the child or subclass.

⭐ Syntax

class Child extends Parent

📝 Example

class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

⭐ Advantages

  • Code reusability
  • Reduced duplication
  • Supports hierarchical relationships
  • Helps implement polymorphism
{% elif topic == "polymorphism" %}

Polymorphism

Polymorphism means "many forms". It allows the same method or interface to behave differently.

📘 Concept Summary

Polymorphism is an important feature of object-oriented programming. Java supports compile-time and runtime polymorphism.

⭐ Method Overloading

Method overloading occurs when multiple methods have the same name but different parameters.

int add(int a, int b)

int add(int a, int b, int c)

⭐ Method Overriding

Method overriding occurs when a child class provides its own implementation of a method inherited from the parent class.

class Dog extends Animal {

    void sound() {
        System.out.println("Bark");
    }
}

💡 Remember

  • Overloading → compile-time polymorphism
  • Overriding → runtime polymorphism
{% elif topic == "interfaces" %}

Interfaces

Interfaces are used to define a contract that implementing classes must follow.

📘 Concept Summary

An interface can contain method declarations and constants. A class uses the implements keyword to implement an interface.

📝 Example

interface Animal {

    void sound();
}

class Dog implements Animal {

    public void sound() {
        System.out.println("Bark");
    }
}

⭐ Why Use Interfaces?

  • Supports abstraction.
  • Defines common behavior.
  • Helps achieve loose coupling.
  • A class can implement multiple interfaces.
{% elif topic == "collections" %}

Collections

Java Collections provide classes and interfaces for storing and manipulating groups of objects.

📘 Concept Summary

Collections are useful when the amount of data may change dynamically. Common collection types include List, Set and Map.

⭐ ArrayList

ArrayList is an ordered collection that can dynamically grow in size.

ArrayList<String> names = new ArrayList<>();

names.add("Java");
names.add("Python");

⭐ HashSet

HashSet stores unique elements and does not allow duplicate values.

HashSet<Integer> numbers = new HashSet<>();

numbers.add(10);
numbers.add(20);

⭐ HashMap

HashMap stores data using key-value pairs.

HashMap<Integer, String> students = new HashMap<>();

students.put(1, "Rashmitha");

⭐ Common Collections

  • ArrayList
  • LinkedList
  • HashSet
  • TreeSet
  • HashMap
  • TreeMap
{% elif topic == "exception" %}

Exception Handling

Exception handling is used to manage unexpected problems that occur during program execution.

📘 Concept Summary

An exception is an event that interrupts the normal execution of a program. Java provides try, catch, finally, throw and throws for exception handling.

⭐ try-catch

Code that may produce an exception is placed inside the try block. The catch block handles the exception.

try {
    int result = 10 / 0;
} catch(ArithmeticException e) {
    System.out.println("Cannot divide by zero");
}

⭐ finally

The finally block is generally used for cleanup work and executes after the try/catch processing.

try {
    // code
} finally {
    // cleanup code
}

⭐ Common Exceptions

  • ArithmeticException
  • NullPointerException
  • ArrayIndexOutOfBoundsException
  • NumberFormatException
  • IOException

File Handling

File handling allows Java programs to create, read, write and modify files.

📘 Concept Summary

Java provides classes such as File, FileReader, FileWriter, BufferedReader and BufferedWriter for working with files.

FileWriter writer = new FileWriter("data.txt");
writer.write("Hello Java");

FileReader reader = new FileReader("data.txt");

⭐ Important File Classes

  • FileReader

  • BufferedReader
  • BufferedWriter

{% elif topic == "problem-solving" %}

Problem Solving

Problem solving is one of the most important skills required for coding interviews and placement tests.

📘 Concept Summary

Programming is not only about knowing syntax. You must understand a problem, create a logical approach and convert that approach into code.

⭐ Problem Solving Steps

  • Understand the problem completely.
  • Identify the input.
  • Identify the expected output.
  • Find constraints.
  • Break the problem into smaller parts.
  • Develop an algorithm.
  • Write the Java code.
  • Test the solution.
  • Optimize if necessary.

📝 Example Problem

Find the largest number among three numbers.

int a = 10;
int b = 25;
int c = 15;

int largest = a;

if(b > largest) {
    largest = b;
}

if(c > largest) {
    largest = c;
}

System.out.println(largest);

⭐ Important Practice Areas

  • Number problems
  • Array problems
  • String problems
  • Searching
  • Sorting
  • Pattern programs
  • Recursion
  • Object-oriented problems
  • Basic data structures

💡 Important Tip

First solve the problem manually using an example. Then convert your logic into Java code.
