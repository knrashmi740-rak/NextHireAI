C Basics

Learn the fundamentals of C programming, syntax, program structure and basic input and output.

📘 Concept Summary

C is a general-purpose procedural programming language. It is widely used for system programming, embedded systems and programming fundamentals.

⭐ Important Concepts

  • C is a procedural programming language.
  • C is a compiled language.
  • Every C program contains a main() function.
  • Statements normally end with a semicolon.
  • C is case-sensitive.

💻 First C Program

#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}

💡 Important Tip

Always include the required header files and remember to write the main() function correctly.

{% elif topic == "variables" %}

Variables & Data Types

Learn how C stores different types of information using variables and data types.

📘 Concept Summary

A variable is a named memory location used to store a value. Every variable in C has a data type.

⭐ Important Data Types

  • int - Integer values
  • float - Decimal values
  • double - Large decimal values
  • char - Single character

📝 Example

int age = 20;

float marks = 85.5;

char grade = 'A';

💡 Important Tip

Choose the appropriate data type according to the value you want to store.

{% elif topic == "operators" %}

Operators

Operators are symbols used to perform operations on variables and values.

📘 Concept Summary

C provides arithmetic, relational, logical, assignment and other types of operators.

⭐ Arithmetic Operators

+   Addition

-   Subtraction

*   Multiplication

/   Division

%   Modulus

📝 Example

int a = 10;
int b = 3;

printf("%d", a + b);

⭐ Relational Operators

==   Equal to

!=   Not equal to

>   Greater than

<   Less than

>=   Greater than or equal to

<=   Less than or equal to
{% elif topic == "conditions" %}

Conditional Statements

Conditional statements are used to make decisions in C programs.

📘 Concept Summary

C provides if, if-else and else-if statements for decision making.

⭐ if Statement

if (age >= 18)
{
    printf("Eligible");
}

⭐ if-else Statement

if (number > 0)
{
    printf("Positive");
}
else
{
    printf("Negative");
}
{% elif topic == "loops" %}

Loops

Loops are used to execute a block of code repeatedly.

📘 Concept Summary

C provides for, while and do-while loops.

⭐ for Loop

for (int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

⭐ while Loop

int i = 1;

while (i <= 5)
{
    printf("%d ", i);
    i++;
}
{% elif topic == "functions" %}

Functions

Functions are reusable blocks of code designed to perform a particular task.

📘 Concept Summary

Functions make programs modular, reusable and easier to understand.

⭐ Function Syntax

return_type function_name(parameters)

📝 Example

int add(int a, int b)
{
    return a + b;
}
{% elif topic == "arrays" %}

Arrays

Arrays are used to store multiple values of the same data type in a single variable.

📘 Concept Summary

Array elements are stored in contiguous memory locations and are accessed using indexes.

📝 Example

int numbers[5] = {10, 20, 30, 40, 50};

printf("%d", numbers[0]);
{% elif topic == "strings" %}

Strings

Strings are sequences of characters terminated by a null character in C.

📘 Concept Summary

C does not have a separate built-in string type. Strings are generally stored using character arrays.

📝 Example

char name[] = "Rashmitha";

printf("%s", name);
{% elif topic == "pointers" %}

Pointers

Pointers are variables that store the memory address of another variable.

📘 Concept Summary

Pointers are an important feature of C and are commonly used for memory management and arrays.

📝 Example

int number = 10;

int *ptr = &number;

printf("%d", *ptr);
{% elif topic == "structures" %}

Structures

Structures allow us to group different types of data under one name.

📘 Concept Summary

A structure is a user-defined data type that can contain members of different data types.

📝 Example

struct Student
{
    int age;
    float marks;
};
{% elif topic == "unions" %}

Unions

A union is a user-defined data type in which all members share the same memory location.

⭐ Important Point

  • All members share memory.
  • Only one member is normally used at a time.
  • Union size depends mainly on its largest member.

📝 Example

union Data
{
    int number;
    float value;
};
{% elif topic == "memory" %}

Dynamic Memory

Dynamic memory allocation allows programs to allocate memory during runtime.

⭐ Important Functions

  • malloc()
  • calloc()
  • realloc()
  • free()

📝 Example

int *ptr;

ptr = (int*) malloc(5 * sizeof(int));

free(ptr);

{% elif topic == "recursion" %}

Recursion

Recursion occurs when a function calls itself.

📘 Concept Summary

A recursive function must have a base condition to stop further calls.

📝 Example

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

Problem Solving

Problem solving is an important skill for coding interviews and placement preparation.

⭐ Problem Solving Steps

  • Understand the problem.
  • Identify inputs and outputs.
  • Break the problem into smaller steps.
  • Design an algorithm.
  • Write the C program.
  • Test different cases.
  • Optimize when required.

💡 Important Tip

Understand the logic first and then convert the logic into C code.
