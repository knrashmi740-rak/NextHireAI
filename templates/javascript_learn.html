JavaScript Basics

Learn the basic concepts of JavaScript, including syntax, statements, comments and how JavaScript works inside a web page.

📘 Concept Summary

JavaScript is a high-level programming language mainly used to make web pages interactive and dynamic.

HTML provides the structure of a webpage, CSS provides styling, and JavaScript adds behavior and interaction.

JavaScript can also be used outside the browser, for example with Node.js to build backend applications.

⭐ Features of JavaScript

  • JavaScript is a high-level language.
  • It is commonly used for web development.
  • It supports object-oriented programming.
  • It supports functional programming concepts.
  • JavaScript is dynamically typed.
  • It can run directly in modern web browsers.
  • It can also be used for server-side programming.

⭐ JavaScript Syntax

JavaScript statements are instructions that tell the computer what to do.

let name = "Rashmitha";

console.log(name);

The first statement creates a variable and the second statement displays its value in the console.

⭐ Comments

Comments are used to explain code. They are ignored during program execution.

// This is a single-line comment

/* This is a
multi-line comment */

📝 First JavaScript Program

console.log("Hello World");

console.log() is commonly used to display information in the browser's developer console.

{% elif topic == "variables" %}

Variables & Data Types

Variables are used to store information that a program can use and manipulate.

📘 Concept Summary

JavaScript provides three keywords for declaring variables: var, let and const.

In modern JavaScript, let and const are generally preferred over var.

⭐ let

let is used when the value of a variable may change.

let age = 20;
age = 21;

console.log(age);

⭐ const

const is used when a variable should not be reassigned after it has been created.

const pi = 3.14;

console.log(pi);

⭐ Important Data Types

  • Number: Integer and decimal numbers.
  • String: Text data.
  • Boolean: true or false.
  • Undefined: A variable without a value.
  • Null: Represents an intentional empty value.
  • Object: Stores related data and properties.
  • Array: Stores multiple values in an ordered collection.

📝 Example

let name = "Rashmitha";
let age = 20;
let percentage = 85.5;
let passed = true;

{% elif topic == "conditions" %}

Conditional Statements

Conditional statements allow JavaScript programs to make decisions based on conditions.

📘 Concept Summary

The main conditional statements in JavaScript are if, else if, else and switch.

⭐ if Statement

let age = 20;

if (age >= 18) {
    console.log("Adult");
}

⭐ if-else

let marks = 75;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

⭐ else-if Ladder

if (marks >= 90) {
    console.log("A");
} else if (marks >= 75) {
    console.log("B");
} else {
    console.log("C");
}

⭐ switch

switch is useful when one value needs to be compared with several possible values.

let day = 1;

switch (day) {
    case 1:
        console.log("Monday");
        break;

    default:
        console.log("Invalid day");
}
{% elif topic == "loops" %}

Loops

Loops are used when the same block of code needs to execute repeatedly.

📘 Concept Summary

JavaScript provides for, while and do-while loops. Loops are especially useful when processing arrays, strings and repeated calculations.

⭐ for Loop

A for loop is useful when the number of iterations is known.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

⭐ while Loop

A while loop checks the condition before each iteration.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

⭐ do-while Loop

A do-while loop executes its body at least once, even if the condition is initially false.

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

⭐ break and continue

  • break: Stops the loop completely.
  • continue: Skips the current iteration.
{% elif topic == "functions" %}

Functions

Functions are reusable blocks of code designed to perform a specific task.

📘 Concept Summary

Functions help divide a large program into smaller pieces. They improve code organization, reusability and readability.

⭐ Function Declaration

function add(a, b) {
    return a + b;
}

let result = add(10, 20);
console.log(result);

⭐ Parameters

Parameters are values received by a function. They allow the same function to work with different input values.

function greet(name) {
    console.log("Hello " + name);
}

greet("Rashmitha");

⭐ Arrow Functions

Arrow functions provide a shorter syntax for writing functions.

const add = (a, b) => a + b;

console.log(add(5, 10));
{% elif topic == "arrays" %}

Arrays

Arrays are used to store multiple values inside a single variable.

📘 Concept Summary

JavaScript arrays are ordered collections. Array indexes start from 0.

⭐ Creating an Array

let numbers = [10, 20, 30, 40];

⭐ Accessing Elements

console.log(numbers[0]);
console.log(numbers[2]);

The first statement prints 10 and the second statement prints 30.

⭐ Important Array Methods

  • push() - Adds an element at the end.
  • pop() - Removes the last element.
  • shift() - Removes the first element.
  • unshift() - Adds an element at the beginning.
  • slice() - Creates a portion of an array.
  • includes() - Checks whether a value exists.

📝 Example

let fruits = ["Apple", "Mango"];

fruits.push("Orange");

console.log(fruits);

DOM Manipulation

DOM manipulation allows JavaScript to access and change HTML elements on a webpage.

📘 What is DOM?

DOM stands for Document Object Model. The browser converts an HTML document into a tree-like structure called the DOM.

JavaScript can use the DOM to change text, styles, attributes and elements dynamically.

⭐ Selecting an Element

document.getElementById("title");

⭐ Changing Text

document.getElementById("title").textContent = "Hello";

⭐ Changing Style

document.getElementById("title").style.color = "blue";

{% elif topic == "async" %}

Asynchronous JavaScript

Asynchronous programming allows JavaScript to start a task and continue executing other code while waiting for the task to finish.

📘 Concept Summary

Asynchronous programming is commonly used when working with timers, network requests and APIs.

⭐ setTimeout()

setTimeout(function() {
    console.log("Hello");
}, 2000);

The callback executes after approximately two seconds.

⭐ Promises

A Promise represents the eventual completion or failure of an asynchronous operation.

let promise = new Promise(function(resolve, reject) {
    resolve("Success");
});

⭐ async and await

async and await provide a cleaner way to work with Promises.

async function getData() {
    let response = await fetch(url);
}
{% elif topic == "error-handling" %}

Error Handling

Error handling helps JavaScript programs deal with unexpected situations without crashing unexpectedly.

📘 Concept Summary

JavaScript provides try, catch, finally and throw for handling errors.

⭐ try-catch

try {
    let result = unknownFunction();
} catch (error) {
    console.log("An error occurred");
}

⭐ finally

The finally block executes after the try/catch processing.

try {
    console.log("Try");
} catch (error) {
    console.log("Error");
} finally {
    console.log("Finished");
}
{% elif topic == "problem-solving" %}

JavaScript Problem Solving

Problem solving is an important skill for coding interviews and placement preparation.

📘 Concept Summary

Knowing JavaScript syntax is only the first step. You should also learn how to analyze a problem, create an algorithm and convert your logic into code.

⭐ Problem Solving Steps

  • Understand the problem.
  • Identify the input.
  • Identify the expected output.
  • Check the constraints.
  • Break the problem into smaller parts.
  • Create an algorithm.
  • Write the JavaScript code.
  • Test normal and edge cases.
  • Optimize the solution when necessary.

📝 Example Problem

Find the largest number in an array.

let numbers = [10, 25, 15, 40, 20];

let largest = numbers[0];

for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
        largest = numbers[i];
    }
}

console.log(largest);

The program starts with the first element as the largest value and compares every remaining element with it.

⭐ Important Practice Areas

  • Number problems
  • Array problems
  • String problems
  • Searching
  • Sorting
  • Pattern programs
  • Recursion
  • Object-based problems
  • DOM problems

💡 Important Tip

First solve the problem manually using a small example. Then convert your logic into JavaScript code.
