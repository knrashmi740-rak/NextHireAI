C++ Basics

Learn the fundamentals of C++ programming.

📘 Concept Summary

C++ is a general-purpose programming language widely used for software development, competitive programming and system programming.

⭐ Important Concepts

  • C++ is a compiled language.
  • C++ supports object-oriented programming.
  • C++ is case-sensitive.
  • C++ supports functions, classes and objects.

📝 First C++ Program

#include <iostream>

using namespace std;

int main() {
    cout << "Hello World";
    return 0;
}
{% elif topic == "variables" %}

Variables & Data Types

Learn how C++ stores different types of data.

📘 Concept Summary

A variable is a named memory location used to store data.

⭐ Common Data Types

  • int - Integer
  • float - Decimal number
  • double - Large decimal value
  • char - Character
  • bool - True or False
  • string - Text

📝 Example

int age = 20;
float marks = 85.5;
char grade = 'A';
bool passed = true;

{% elif topic == "conditions" %}

Conditional Statements

Conditional statements are used for decision making.

⭐ if Statement

if (age >= 18) {
    cout << "Eligible";
}

⭐ if-else

if (marks >= 40) {
    cout << "Pass";

    cout << "Fail";
}
{% elif topic == "loops" %}

Loops

Loops execute a block of code repeatedly.

⭐ for Loop

for(int i = 1; i <= 5; i++) {
    cout << i;
}

⭐ while Loop

int i = 1;
while(i <= 5) {
    cout << i;
    i++;
}
