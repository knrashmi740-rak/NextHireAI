Data Interpretation

Learn how to analyze tables, charts and graphs using mathematical calculations.

📘 Concept Summary

Data Interpretation involves understanding and analyzing numerical data represented through tables, bar graphs, pie charts and line graphs.

⭐ Important Types

  • Table Data Interpretation
  • Bar Graph
  • Pie Chart
  • Line Graph
  • Caselet DI

⭐ Important Formulas

Percentage Change =

(New Value - Old Value) / Old Value × 100
Average =

Total Value / Number of Values
Pie Chart Angle =

Value / Total × 360°

💡 Shortcuts & Tricks

  • Read the complete graph before calculating.
  • Approximation saves time in large calculations.
  • Compare values instead of calculating everything.
  • Learn percentage conversion quickly.

📝 Example

A company sales increased from 200 units to 300 units. Find percentage increase.

Increase = 300 - 200

= 100

Percentage Increase = 100/200 ×100

= 50%
