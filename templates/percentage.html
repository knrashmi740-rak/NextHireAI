Percentage

Learn the basics of percentage, formulas, shortcuts and placement tricks.

📘 Concept Summary

Percentage means "per hundred". It is a way of expressing a number as a fraction of 100. It is widely used in aptitude problems like profit & loss, marks calculation, discounts, interest and data interpretation.

⭐ Important Formulas

Percentage =
(Value / Total Value) × 100
Percentage Change =
(Change in Value / Original Value) × 100
New Value after Increase =
Original Value × (100 + Increase %) / 100
New Value after Decrease =
Original Value × (100 - Decrease %) / 100

💡 Important Tricks

  • To convert fraction into percentage: Multiply the fraction by 100.
  • If a value increases by 20%, multiply by 1.20.
  • If a value decreases by 20%, multiply by 0.80.
  • Successive percentage changes are not directly added.
  • Always consider the original value while calculating percentage change.

📝 Example

A student scored 450 marks out of 500. Find the percentage.

Percentage = (450 / 500) × 100

= 90%
